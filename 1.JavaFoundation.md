# Java Foundation Practice Project: Student Management System

Let's build a console-based Student Management System to check your Phase 1 Java foundation before moving on to Servlet and Spring Boot.

This project is deliberately built with core Java only — no Spring, no database, no external libraries. You'll practice the same Java concepts that you'll later use in backend development.

You'll start with a working project, then extend it with challenges to test whether you understand the code rather than simply copying it.

```

└── src/
```

The design separates three responsibilities:
```
|--Main.java
|    |
|    `--Console menu, Scanner input, and user interaction.

|--StudentService.java
|    |

|
|--Student.java
|    |

```
This is a simple version of separation of concerns — a principle you'll later see in Spring's Controller, Service, and Repository layers.

# 4. Complete starter code

## File 1 — `Student.java`

This class represents one student.


```Java
public class Student {

    private int id;
    private String name;
    private int age;
    private String email;
    private double score;

    public Student(int id, String name, int age,
                   String email, double score) {
        this.id = id;
        this.name = name;
        this.age = age;
        this.email = email;
        this.score = score;
    }

    // Getters
    public int getId() {
        return id;
    }

    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }

    public String getEmail() {
        return email;
    }

    public double getScore() {
        return score;
    }

    // Setters
    public void setName(String name) {
        this.name = name;
    }

    public void setAge(int age) {
        this.age = age;
    }

    public void setEmail(String email) {
        this.email = email;
    }

    public void setScore(double score) {
        this.score = score;
    }

    @Override
    public String toString() {
        return String.format(
            "ID: %d | Name: %s | Age: %d | Email: %s | Score: %.2f",
            id, name, age, email, score
        );
    }
}
```

### Concepts to understand

* Why are the fields `private`?

* Why do we use a constructor?

* Why does the ID have no setter?

* What does `@Override` mean?

* Why is `String.format()` useful?

The ID is intentionally immutable through the public API: once a student is created, you cannot change its ID using a setter.

## File 2 — `StudentService.java`

This class manages the student collection and implements the business logic.


```Java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

public class StudentService {

    private final List<Student> students = new ArrayList<>();

    // Add a student
    public boolean addStudent(Student student) {
        if (findStudentById(student.getId()) != null) {
            return false;
        }

        students.add(student);
        return true;
    }

    // List all students
    public List<Student> getAllStudents() {
        return new ArrayList<>(students);
    }

    // Search by ID
    public Student findStudentById(int id) {
        for (Student student : students) {
            if (student.getId() == id) {
                return student;
            }
        }

        return null;
    }

    // Update student
    public boolean updateStudent(
            int id,
            String name,
            int age,
            String email,
            double score) {

        Student student = findStudentById(id);

        if (student == null) {
            return false;
        }

        student.setName(name);
        student.setAge(age);
        student.setEmail(email);
        student.setScore(score);

        return true;
    }

    // Delete student
    public boolean deleteStudent(int id) {
        Student student = findStudentById(id);

        if (student == null) {
            return false;
        }

        return students.remove(student);
    }

    // Sort by score, highest first
    public List<Student> getStudentsSortedByScore() {
        List<Student> result = getAllStudents();

        result.sort(
            Comparator.comparingDouble(Student::getScore)
                      .reversed()
        );

        return result;
    }

    // Calculate average score
    public double getAverageScore() {
        if (students.isEmpty()) {
            return 0.0;
        }

        double total = 0;

        for (Student student : students) {
            total += student.getScore();
        }

        return total / students.size();
    }
}
```

### Concepts to understand

|Code|Java concept|
| --- | --- |
|`List<Student>`|Generics and interfaces|
|`new ArrayList<>()`|Object creation and polymorphism|
|`private final`|Encapsulation and reference reassignment rules|
|`for (Student student : students)`|Enhanced for loop|
|`Comparator.comparingDouble()`|Comparator and method references|
|`return null`|Object references and missing values|
|`new ArrayList<>(students)`|Defensive copy of the collection|

Important: `getAllStudents()` returns a new list, but the `Student` objects inside it are still shared references. This is a shallow copy.

## File 3 — `Main.java`

This is the console interface.



```Java
import java.util.List;
import java.util.Scanner;

public class Main {

    private static final Scanner scanner =
            new Scanner(System.in);

    private static final StudentService service =
            new StudentService();

    public static void main(String[] args) {

        boolean running = true;

        while (running) {
            printMenu();

            int choice = readInt("Choose an option: ");

            switch (choice) {
                case 1 -> addStudent();
                case 2 -> listStudents();
                case 3 -> searchStudent();
                case 4 -> updateStudent();
                case 5 -> deleteStudent();
                case 6 -> sortStudents();
                case 7 -> showAverageScore();
                case 0 -> {
                    running = false;
                    System.out.println("Goodbye!");
                }
                default ->
                    System.out.println("Invalid option.");
            }

            System.out.println();
        }

        scanner.close();
    }

    private static void printMenu() {
        System.out.println("===== Student Management =====");
        System.out.println("1. Add student");
        System.out.println("2. List students");
        System.out.println("3. Search student");
        System.out.println("4. Update student");
        System.out.println("5. Delete student");
        System.out.println("6. Sort by score");
        System.out.println("7. Average score");
        System.out.println("0. Exit");
    }

    private static void addStudent() {
        int id = readInt("ID: ");

        String name = readLine("Name: ");
        int age = readInt("Age: ");
        String email = readLine("Email: ");
        double score = readDouble("Score: ");

        Student student =
                new Student(id, name, age, email, score);

        if (service.addStudent(student)) {
            System.out.println("Student added.");
        } else {
            System.out.println("ID already exists.");
        }
    }

    private static void listStudents() {
        List<Student> students = service.getAllStudents();

        if (students.isEmpty()) {
            System.out.println("No students found.");
            return;
        }

        for (Student student : students) {
            System.out.println(student);
        }
    }

    private static void searchStudent() {
        int id = readInt("Enter student ID: ");

        Student student = service.findStudentById(id);

        if (student == null) {
            System.out.println("Student not found.");
        } else {
            System.out.println(student);
        }
    }

    private static void updateStudent() {
        int id = readInt("Enter student ID: ");

        String name = readLine("New name: ");
        int age = readInt("New age: ");
        String email = readLine("New email: ");
        double score = readDouble("New score: ");

        boolean updated = service.updateStudent(
                id, name, age, email, score
        );

        System.out.println(
                updated ? "Student updated."
                        : "Student not found."
        );
    }

    private static void deleteStudent() {
        int id = readInt("Enter student ID: ");

        boolean deleted = service.deleteStudent(id);

        System.out.println(
                deleted ? "Student deleted."
                        : "Student not found."
        );
    }

    private static void sortStudents() {
        List<Student> students =
                service.getStudentsSortedByScore();

        for (Student student : students) {
            System.out.println(student);
        }
    }

    private static void showAverageScore() {
        double average = service.getAverageScore();

        System.out.printf("Average score: %.2f%n", average);
    }

    private static int readInt(String prompt) {
        while (true) {
            System.out.print(prompt);

            try {
                return Integer.parseInt(
                        scanner.nextLine().trim()
                );
            } catch (NumberFormatException e) {
                System.out.println("Please enter an integer.");
            }
        }
    }

    private static double readDouble(String prompt) {
        while (true) {
            System.out.print(prompt);

            try {
                return Double.parseDouble(
                        scanner.nextLine().trim()
                );
            } catch (NumberFormatException e) {
                System.out.println("Please enter a number.");
            }
        }
    }

    private static String readLine(String prompt) {
        System.out.print(prompt);
        return scanner.nextLine().trim();
    }
}
```

Expected: The second student should not be added.

Expected: The program should report that the student wasn't found.

# 7. Knowledge check — can you explain your own code?

Try answering these without looking at the implementation.

2. What happens when `findStudentById()` returns null?

3. Why does `getStudentsSortedByScore()` create a copy before sorting?

4. Why is the Scanner helper using `nextLine()` instead of mixing `nextInt()` and `nextLine()`?

5. What is the difference between `==` and `equals()` when comparing objects?

6. What is the difference between a static method and an instance method?
