# IntelliJ IDEA IDE Cheatsheet

A practical IntelliJ IDEA cheatsheet for Java development, covering navigation, coding, debugging, refactoring, and Maven/Spring Boot workflows.

Shortcuts below use the default Windows/Linux keymap (including Ubuntu). macOS equivalents are included where useful.

## 1. Essential shortcuts

These are the shortcuts worth memorizing first.

Search Everywhere

Find classes, files, actions, settings, and symbols.

Shift × 2

Find Action

Search for any IDE command.

Ctrl + Shift + A

Quick Definition

Preview a method or class without navigating away.

Ctrl + Shift + I

Go to Declaration

Jump to a method, variable, or class definition.

Ctrl + B

Generate Code

Generate constructors, getters, setters, and more.

Alt + Insert

Reformat Code

Format the current file or selected code.

Ctrl + Alt + L

Rename

Rename a symbol and update its usages.

Shift + F6

## 5. Debugging

Toggle breakpoint

Set or remove a breakpoint on the current line.

Ctrl + F8

Debug

Start debugging the current run configuration.

Shift + F9

Step Over

Execute the current line without entering a method.

F8

Step Into

Enter the method being called.

F7

Step Out

Finish the current method and return to its caller.

Shift + F8

Resume Program

Continue execution until the next breakpoint.

F9

### Useful debugging features

* Watches: Evaluate expressions repeatedly while debugging.

* Evaluate Expression: `Alt + F8` — execute an expression in the current debugging context.

* Conditional breakpoints: Stop only when a condition is true.

* Field and object inspection: Expand objects in the Variables panel to inspect their fields.

* Exception breakpoints: Stop when specified exceptions are thrown.

## 8. Maven and Spring Boot workflow

Maven

Use the Maven tool window to manage dependencies, lifecycle goals, and plugins.

1. Open `pom.xml` and edit dependencies.

2. Reload the Maven project to download dependencies and refresh the project model.

3. Use the Maven tool window to run lifecycle goals such as `clean`, `test`, and `package`.

4. Run or debug your Spring Boot application from its main class, or create a Spring Boot run configuration.

5. Use breakpoints in controllers, services, and repositories to follow an HTTP request through the application.

### Handy Maven terminal commands

Bash

```
# Compile
./mvnw compile

# Run tests
./mvnw test

# Package
./mvnw package

# Run Spring Boot
./mvnw spring-boot:run

# Clean and package
./mvnw clean package
```

On Windows, use `mvnw.cmd` instead of `./mvnw`.

## My recommended learning order for Java development

1. Navigation: Shift × 2, Ctrl + B, Alt + F7.

2. Editing: Alt + Enter, Alt + Insert, Ctrl + Alt + L.

3. Refactoring: Shift + F6, Extract Method.

4. Debugging: breakpoints, F8, F7, F9.

5. Project workflow: Maven, Git, Spring Boot run configurations.

Important: IntelliJ IDEA's shortcuts can vary by version, keymap, operating system, and customized settings. If a shortcut doesn't work, use Find Action to locate the command and inspect its current key binding.
