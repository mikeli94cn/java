In Java, the scope of a variable refers to the specific region of a program's code where that variable is visible, accessible, and can be used.

The general rule of thumb in Java is that a variable is only accessible within the set of curly braces { } where it was declared. Once the program exits those curly braces, the variable is destroyed and can no longer be used.

------------------------------
## Why Variable Scope Matters

* Memory Management: Java allocates memory when a variable comes into scope and frees up that memory (via garbage collection) when it goes out of scope.
* Name Reuse: You can reuse the same variable name in different parts of your program as long as their scopes do not overlap.
* Security & Cleanliness: Restricting a variable's scope prevents other parts of your program from accidentally changing its value.

------------------------------
## The 3 Main Types of Variable Scope in Java
We can categorize variable scope into three primary levels, ranging from the broadest access to the most restricted access:
## 1. Class-Level Scope (Instance & Static Variables)
Variables declared directly inside a class (but outside any method or loop) are called fields or class variables. They are accessible by any method within that class.
```java
public class User {
    // Class-level scope: accessible anywhere inside this class
    String username = "Alex"; 

    public void printName() {
        System.out.println(username); // Works perfectly
    }

    public void checkStatus() {
        if (username.length() > 0) { // Works perfectly here too
            System.out.println("Active");
        }
    }
}
```
## 2. Method-Level Scope (Local Variables)
Variables declared inside a specific method are called local variables. They only exist from the line they are declared down to the end of that specific method. Other methods in the same class cannot see or use them.
```java
public class Calculator {

    public void addNumbers() {
        // Method-level scope: only visible inside addNumbers()
        int total = 10 + 5; 
        System.out.println(total); 
    }

    public void printTotal() {
        // ERROR! The variable 'total' does not exist in this scope
        System.out.println(total); 
    }
}
```
## 3. Block-Level Scope (Loop & Conditional Variables)
A block is code enclosed between an opening { and a closing } (like if statements, for loops, or while loops). Variables declared inside a block are strictly restricted to that block and cannot be accessed outside of it—even within the same method.
```java
public class LoopExample {
    public void runLoop() {
        int standardBonus = 50; // Method scope

        for (int i = 0; i < 3; i++) {
            // Block scope: 'i' and 'tempResult' only exist inside this loop
            int tempResult = standardBonus * i; 
            System.out.println(tempResult);
        }

        // ERROR! 'i' is out of scope here
        System.out.println(i); 
        
        // ERROR! 'tempResult' is out of scope here
        System.out.println(tempResult); 
    }
}
```
------------------------------
## Summary Table

| Scope Level | Where is it Declared? | Where is it Accessible? |
|---|---|---|
| Class Scope | Inside a class, outside any methods. | Anywhere inside that class. |
| Method Scope | Inside a method. | Only inside that specific method. |
| Block Scope | Inside a loop, if statement, or { } block. | Only inside that specific block. |
