In advanced Java class design, a nested class is any class that is defined directly inside the body of another enclosing class. They are used to logically group classes that are only needed by one specific component, resulting in more readable, encapsulated, and maintainable code.

Java splits nested classes into two main categories: Static Nested Classes and Inner Classes (which are non-static).


## The 4 Types of Nested Classes
```
                       [ Nested Classes ]
                               │
               ┌───────────────┴───────────────┐
               ▼                               ▼
     [ Static Nested Class ]            [ Inner Classes ] (Non-Static)
  (Treated as a top-level class)               │
                               ┌───────────────┼───────────────┐
                               ▼               ▼               ▼
                        [ Member Class ] [ Local Class ] [ Anonymous Class ]
```

### 1. Static Nested Class (Scoped Blueprints)
Although it is physically declared inside an outer class, a static nested class behaves exactly like a regular top-level class. It is bundled inside purely for clean namespace organization.

* The Access Rule: It cannot access non-static (instance) variables or methods of the outer class directly.
* How to Instantiate: You do not need an object of the outer class to create it.
```java
public class OuterCompany {
    private static String companyName = "TechCorp";
    private String clientSessionId = "ABC-123";

    // 1. Static Nested Class
    public static class CorporateAddress {
        public void printLocation() {
            System.out.println("HQ location for: " + companyName); // Allowed
            // System.out.println(clientSessionId); // ❌ COMPILER ERROR: Cannot see instance data
        }
    }
}
```

* Instantiation Syntax: `OuterCompany.CorporateAddress addr = new OuterCompany.CorporateAddress();`


### 2. Member Inner Class (Instance-Bound)
A member inner class is non-static and defined at the class level. It is directly tied to the instance of the outer class.

* The Access Rule: It can effortlessly access all fields and methods of the outer class, including those marked private.
* How to Instantiate: You must create an instance of the outer class first before you can spawn the inner class.
```java
public class OuterBank {
    private double vaultBalance = 500000.00;

    // 2. Member Inner Class
    public class BankTeller {
        public void checkVault() {
            // Can see the private parent fields directly
            System.out.println("Current balance: $" + vaultBalance); 
        }
    }
}
```

* Instantiation Syntax:
```java
OuterBank bank = new OuterBank();
OuterBank.BankTeller teller = bank.new BankTeller(); // Notice the 'bank.new' syntax!
```


### 3. Local Class (Method-Scoped)
A local class is an inner class defined inside a specific block of code, usually inside a method body. It is completely hidden from the rest of the class and only exists while that method is actively executing.

* The Access Rule: It can read the local variables of the enclosing method, but only if those variables are final or effectively final (meaning their value never changes after assignment).
```java
public class RouteManager {
    public void calculateDelivery(String packageId) {
        String shippingZone = "Zone B"; // Effectively final local variable

        // 3. Local Class (Hidden inside the method)
        class LocalDeliveryTracker {
            void logProgress() {
                System.out.println("Tracking " + packageId + " in " + shippingZone);
            }
        }

        // Must be instantiated and used right inside the method
        LocalDeliveryTracker tracker = new LocalDeliveryTracker();
        tracker.logProgress();
    }
}
```

### 4. Anonymous Inner Class (One-Time inline Expression)
An anonymous inner class is an inner class that has no name. It combines declaration and instantiation into a single, compact step. 

You use it when you want to quickly override a class method or implement an interface on the fly for a one-time operation.
```java
abstract class SpecialDiscount {
    abstract void applyDiscount();
}
public class StoreCheckout {
    public void checkout() {
        // 4. Anonymous Inner Class
        // Declaring a nameless child class that extends SpecialDiscount inline
        SpecialDiscount blackFridayDeal = new SpecialDiscount() {
            @Override
            void applyDiscount() {
                System.out.println("Applying a massive 50% seasonal discount!");
            }
        }; // Mandatory semicolon

        blackFridayDeal.applyDiscount();
    }
}
```

## Summary Architectural Matrix

| Class Type | Has access to Outer instance data? | Requires an Outer object to instantiate? | Where is it written? |
|---|---|---|---|
| Static Nested | No | No | Directly inside the class body. |
| Member Inner | Yes | Yes | Directly inside the class body. |
| Local | Yes | Only within its host method. | Inside a method body. |
| Anonymous | Yes | Instantiated instantly inline. | Inside a statement expression. |
