In Java, a class serves as the blueprint or template from which individual objects are created. Think of a class as a blueprint for a house: it defines the structure, features, and layout, while the physical houses built from it are the objects.
Every custom data type you create in Java requires a defined class structure, which follows a strict and predictable layout.

------------------------------
## The Standard Component Order of a Java Class
A fully featured Java class generally arranges its components in a top-down order. While not all components are strictly mandatory for every class, they always appear in this sequence:

1. Package Declaration (Where this file lives in the project)
2. Import Statements  (External tools/libraries needed)
3. Class Header       (The name and access level of the class)
4. Variables/Fields   (The data or attributes the class tracks)
5. Constructors       (The code that initializes new objects)
6. Methods            (The actions or behaviors the class can perform)

------------------------------
## Breakdown of the Structure (With Code)
Here is a visual breakdown of a standard Java class structure modeling a Product in an online store:
```java
// 1. PACKAGE DECLARATION
package com.store.inventory;
// 2. IMPORT STATEMENTS
import java.util.Date; 
// 3. CLASS HEADER
public class Product {

    // 4. VARIABLES / FIELDS (Attributes/State)
    private String name;
    private double price;

    // 5. CONSTRUCTORS (Object Creation/Initialization)
    public Product(String productName, double productPrice) {
        this.name = productName;
        this.price = productPrice;
    }

    // 6. METHODS (Behaviors/Actions)
    public void displayDetails() {
        System.out.println("Product: " + name + " | Price: $" + price);
    }
}
```
------------------------------
## Detailed Look at the Core Components
## 1. Package & Imports

* Package: Helps organize code files into folders and prevents naming conflicts. It must be the very first line of code in the file.
* Imports: Tell Java which other classes or external libraries your file needs to use (e.g., importing java.util.Date to track time).

## 2. Class Header
The header declares the existence of the class. It requires:

* An access modifier (usually public), which determines who can use this blueprint.
* The keyword class.
* The Class Name, which must use PascalCase (capitalizing the first letter of every word, like ShoppingCart) and must match the physical file name exactly (ShoppingCart.java).

## 3. Variables / Fields (The "State")
Fields represent the data or attributes that an object will remember. For example, a User class might track a username and an email. They are usually marked private to protect the data from direct external tampering.
## 4. Constructors
A constructor is a special block of code used to initialize a newly created object.

* It has no return type (not even void).
* It must have the exact same name as the class.
* It runs automatically the moment you use the new keyword (e.g., Product p = new Product("Laptop", 999.99);).

## 5. Methods (The "Behavior")
Methods are functions inside the class that define what an object can do or what can be done to it. They can manipulate the class variables, perform calculations, or return data back to the program.
