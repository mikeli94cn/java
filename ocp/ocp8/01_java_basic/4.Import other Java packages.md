In Java, you don’t have to write everything from scratch. Java comes with a massive library of pre-written code—called the Java Class Library—which is organized into packages (essentially folders containing related classes).

To use a class that lives in a different package, you must import it at the very top of your file. This makes the external code visible and accessible to your program.

------------------------------
## The Basic Syntax of an Import
Import statements must be placed at the very top of your source file, after the package declaration (if you have one) but before your class header.
```java
// Syntax: import package.name.ClassName;
import java.util.Scanner; // Imports just the Scanner class
```
Once imported, you can use that class inside your code without any issues:
```java
public class Main {
    public static void main(String[] args) {
        // Scanner is now accessible because of the import above
        Scanner input = new Scanner(System.in); 
    }
}
```
------------------------------
## The Two Ways to Import Packages## 1. Explicit Import (Recommended)
You target the exact class you want to use. This makes your code readable because anyone looking at it knows exactly what dependencies your project relies on.
```java
import java.util.ArrayList;
import java.util.Random;
```
## 2. Wildcard Import (Using *)
If you need to use many different classes from the same package, you can use an asterisk (*). This imports all classes inside that specific package folder.
```java
import java.util.*; // Imports Scanner, ArrayList, Random, etc.
```

* Performance note: Using a wildcard does not slow down your program at runtime or increase your final file size, but it can lead to naming conflicts if two packages have a class with the exact same name.

------------------------------
## The Special Exception: java.lang
You might notice that you've been using classes like String and System without ever writing an import statement.

This is because Java automatically imports the java.lang package into every single Java file behind the scenes. This package contains the fundamental classes required for basic programming language functionality.

------------------------------
## How to Handle Naming Conflicts
Sometimes, two completely different packages contain a class with the exact same name. For example, both java.util.Date and java.sql.Date exist.

If you import both using wildcards or try to import both explicitly, Java will get confused. To fix this, you must bypass the import statement for one of them and use its Fully Qualified Name directly in your code:
```java
public class DateExample {
    public static void main(String[] args) {
        java.util.Date utilityDate = new java.util.Date();
        java.sql.Date sqlDate = new java.sql.Date(0);
    }
}
```
------------------------------
## Commonly Used Packages to Know

* java.util: Contains utility frameworks, collection classes (like ArrayList), a random number generator, and input scanners.
* java.io: Contains classes managing system input and output through data streams, serialization, and the file system.
* java.time: The modern API for handling dates, times, time zones, and periods.
