To create an application that a computer can actually launch, Java relies on three core mechanisms: a mandatory entry point (the main method), a command-line interface toolset to compile and interpret the file, and a built-in stream to send text to the user's screen. 
Here is how these three pieces come together to create a working, executable workflow.

------------------------------
## 1. Creating an Executable App: The main Method
An "executable" Java application is simply a class that contains a specifically structured method named main. The Java Virtual Machine (JVM) explicitly searches for this exact signature to know where your process begins. 

Save the following code into a plain text file named GreetingApp.java: 
```java
public class GreetingApp {
    public static void main(String[] args) {
        // Your program's code starts here
        System.out.println("Application launched successfully!");
    }
}
```
## Syntax Breakdown:

* public: The access level must be public so the external JVM can see and run it.
* static: This allows the JVM to call the method immediately without needing to manually build an object out of the class first.
* void: The method performs actions but does not return any final value data back to the system.
* String[] args: This represents an array of string parameters (arguments) that someone can optionally pass into your app when launching it from a terminal. 


------------------------------
## 2. Running a Java Program from the Command Line
Java uses a two-step cycle: Compile (turning human text into universal bytecode) and Run (interpreting that bytecode via the JVM). 
Open your system's terminal or Command Prompt, use cd to change your directory to the folder where GreetingApp.java is saved, and execute these commands: 

# Step 1: Compile the source file into a bytecode file (.class)
javac GreetingApp.java
# Step 2: Run the compiled class file
java GreetingApp


 
* Note the difference: When compiling with javac, you must include the .java extension. When running with java, you must omit the .class extension and only provide the class name. 
 

------------------------------
## 3. Producing Console Output
To print results, logs, or messages out to the user's screen, Java provides the System.out object, representing the standard output stream. 
There are two primary methods used to print data:

 
* System.out.println(): Prints the text provided inside the parentheses and automatically moves the cursor down to a new line.
* System.out.print(): Prints the text exactly where it is but keeps the cursor on the same line, meaning the next print statement will append right next to it. 
 
```java
System.out.print("Hello ");
System.out.print("World!"); // Outputs: Hello World! (on a single line)

System.out.println("Line 1");
System.out.println("Line 2");// Outputs:// Line 1// Line 2
```
