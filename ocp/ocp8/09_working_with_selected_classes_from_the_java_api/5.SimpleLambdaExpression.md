In Java, Lambda expressions (introduced in Java 8) allow you to treat actions and functions as method arguments. They provide a highly compact, functional way to write code without needing to build entire anonymous classes.

A Predicate is a built-in functional interface located in the java.util.function package. It represents a simple conditional test that takes one input argument and returns a boolean value (true or false).

Here is how you write a lambda expression that acts as a Predicate, and how you pass (consume) it inside another method.

## 1. Writing a Basic Lambda Predicate
A traditional way to check if a number is even requires a full method. A Lambda expression condenses this down to a single line using the arrow syntax (->):
```
    (parameter)  ->   { expressions / business logic }
```
```java
import java.util.function.Predicate;

// Reads as: Take an integer 'n', and check if n % 2 equals 0
Predicate<Integer> isEven = n -> n % 2 == 0;

// To test a predicate manually, you invoke its built-in .test() method
System.out.println(isEven.test(4));  // Outputs: true
System.out.println(isEven.test(7));  // Outputs: false
```

## 2. Consuming a Predicate Inside a Method
To make use of a Predicate, you write a method that accepts a Predicate as an argument. Inside that method, you invoke .test() on the incoming lambda to filter or evaluate your data dynamically.
Here is a complete application that filters an array of scores based on whatever custom Lambda rule you decide to pass into it:
```java
import java.util.ArrayList;
import java.util.List;
import java.util.function.Predicate;

public class LambdaFilterDemo {

    // This method CONSUMES the Lambda Predicate expression
    public static List<Integer> filterScores(List<Integer> scores, Predicate<Integer> condition) {
        List<Integer> filteredList = new ArrayList<>();
        
        for (int score : scores) {
            // Evaluates the lambda rule dynamically at runtime
            if (condition.test(score)) { 
                filteredList.add(score);
            }
        }
        return filteredList;
    }

    public static void main(String[] args) {
        List<Integer> examScores = List.of(45, 78, 92, 60, 85);

        // Scenario A: Pass a lambda to filter out passing grades (>= 70)
        List<Integer> passingScores = filterScores(examScores, score -> score >= 70);
        System.out.println("Passing Scores: " + passingScores); 
        // Outputs: [78, 92, 85]

        // Scenario B: Pass a completely different lambda rule using the exact same method
        List<Integer> failingScores = filterScores(examScores, score -> score < 60);
        System.out.println("Failing Scores: " + failingScores); 
        // Outputs: [45]
    }
}
```

## 3. Combining Lambdas with ArrayLists: .removeIf()
Java has pre-built methods in its Collections API that are designed explicitly to consume Predicate lambdas. 

A highly common example is the .removeIf() method on an ArrayList, which loops through a list and destroys any item that matches your custom true/false lambda expression.
```java
ArrayList<String> names = new ArrayList<>(List.of("Alex", "Bob", "Anna", "Charlie"));

// Consuming a predicate lambda to remove any name that starts with 'A'
names.removeIf(name -> name.startsWith("A"));

System.out.println(names); // Outputs: [Bob, Charlie]
```
