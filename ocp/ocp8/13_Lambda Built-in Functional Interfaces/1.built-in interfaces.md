In advanced Java programming, functional interfaces are the engine that drives Lambda expressions. While you can create your own custom functional interfaces, Java provides a pre-packaged suite of highly flexible templates inside the java.util.function package.
Instead of writing new interfaces for every unique task, you can use these built-in interfaces to pass actions, filter conditions, and transformations directly as parameters.

------------------------------
## The 4 Core Built-In Functional Interfaces
The entire framework relies on four foundational shapes, each defined by what data it takes in (arguments) and what data it spits out (return values).
## 1. Predicate<T> (The Conditional Filter)
A Predicate takes one input argument of type T and returns a primitive boolean (true or false). It is universally used for testing conditions, validation, and filtering data collections.

* Core Method: boolean test(T t) [1]
* Lambda Shape: input -> boolean_condition [1]

import java.util.function.Predicate;
// Check if a string length is longer than 5 characters
Predicate<String> isLongWord = word -> word.length() > 5;
System.out.println(isLongWord.test("Java"));     // Outputs: false
System.out.println(isLongWord.test("Framework")); // Outputs: true

## 2. Consumer<T> (The Action Worker)
A Consumer takes one input argument of type T and returns absolutely nothing (void). It consumes the data to execute an inline action, such as printing text, updating a database, or logging events.

* Core Method: void accept(T t)
* Lambda Shape: input -> System.out.println(input)

import java.util.function.Consumer;
// Consumes a string and prints a formatted notification log
Consumer<String> logger = message -> System.out.println("[LOG]: " + message);
logger.accept("System backup initiated."); // Outputs: [LOG]: System backup initiated.

## 3. Supplier<T> (The Factory Generator)
A Supplier is the exact opposite of a Consumer. It takes zero input arguments but returns a brand-new object of type T. It functions as a lazy factory model that yields data or instantiates objects only when explicitly asked.

* Core Method: T get()
* Lambda Shape: () -> new Object()

import java.util.function.Supplier;
// Supplies a fresh random decimal value on demand
Supplier<Double> randomMaker = () -> Math.random();
System.out.println(randomMaker.get()); // Outputs a random decimal number

## 4. Function<T, R> (The Data Pipeline Transformer)
A Function acts as a mapping bridge. It takes one input argument of type T, processes it, and returns a result of a completely different type R. It is the cornerstone of data manipulation pipelines.

* Core Method: R apply(T t)
* Lambda Shape: input -> converted_output

import java.util.function.Function;
// Takes a String input and returns its Integer length
Function<String, Integer> wordCounter = text -> text.length();int length = wordCounter.apply("Programming"); 
System.out.println(length); // Outputs: 11

------------------------------
## Direct Structural Comparison

| Functional Interface | Generic Type Signature | Abstract Method | Input Count | Return Type | Primary Purpose |
|---|---|---|---|---|---|
| Predicate<T> | <T> | boolean test(T t) [1] | 1 | boolean [1, 5] | Enforce true/false evaluation filters. |
| Consumer<T> | <T> | void accept(T t) | 1 | void | Execute side-effects or logging routines. |
| Supplier<T> | <T> | T get() | 0 | T [5] | Generate or supply factory assets on demand. |
| Function<T, R> | <T, R> | R apply(T t) | 1 | R (Dynamic) [5] | Map, translate, or transform data types. |

## Combining Interfaces in a Real-World Workflow
These interfaces achieve maximum utility when they are combined into pipeline frameworks. Let's see how a single application utilizes all four shapes to process an invoice:

import java.util.function.*;
public class WorkflowDemo {
    public static void main(String[] args) {
        // 1. SUPPLIER generates a base invoice amount
        Supplier<Double> baseCostSupplier = () -> 150.00;
        
        // 2. FUNCTION converts the raw decimal amount into a descriptive receipt string
        Function<Double, String> receiptFormatter = cost -> "Total Invoice: $" + (cost + (cost * 0.10));
        
        // 3. PREDICATE checks if the final formatted invoice counts as high value
        Predicate<String> isPremiumInvoice = invoiceText -> invoiceText.contains("165");
        
        // 4. CONSUMER prints out the resulting logs
        Consumer<String> consolePrinter = System.out::println;

        // Running the synchronized pipeline
        double cost = baseCostSupplier.get();
        String finalReceipt = receiptFormatter.apply(cost);
        
        if (isPremiumInvoice.test(finalReceipt)) {
            consolePrinter.accept(finalReceipt + " [FLAGGED FOR PREMIUM DELIVERY]");
        }
    }
}

## The Execution Output:

Total Invoice: $165.0 [FLAGGED FOR PREMIUM DELIVERY]
