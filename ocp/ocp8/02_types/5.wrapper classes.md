In Java, wrapper classes provide a way to use primitive data types (like int, double, and boolean) as full-featured objects (Integer, Double, and Boolean).
Because wrapper classes are objects, they allow primitives to be used in places that strictly require objects, such as Java Collections (like ArrayList), while also providing a suite of useful utility methods for data conversion.


## The Primitive to Wrapper Match
Each of the eight primitive types has a corresponding wrapper class located in the automatically imported java.lang package:

| Primitive Type | Wrapper Class (Object) |
|---|---|
| int | Integer |
| double | Double |
| boolean | Boolean |
| char | Character |
| byte / short / long / float | Byte / Short / Long / Float |


## 1. Autoboxing and Unboxing
Java simplifies working with wrapper classes by automatically converting between primitives and their corresponding object wrappers.
## Autoboxing (Primitive → Wrapper)
The automatic conversion of a primitive type into its corresponding wrapper object. This is essential when working with data structures like ArrayList.
```java
// Autoboxing: int primitive converts automatically to an Integer object
Integer scoreObject = 95; 
// Mandatory for Collections: ArrayList cannot store primitives
ArrayList<Integer> scoresList = new ArrayList<>();
scoresList.add(100); // int 100 is autoboxed into an Integer object
```
## Unboxing (Wrapper → Primitive)
The automatic conversion of a wrapper object back into its corresponding primitive type.
```java
Integer temperatureObject = 72;
// Unboxing: Integer object converts automatically to an int primitive
int currentTemp = temperatureObject; 
```

## 2. Powerful Utility Methods
Beyond allowing primitives to live inside object-based collections, wrapper classes contain highly useful static methods. The most common use case is parsing Strings into numerical or boolean data.
## Parsing Data From Strings

// Convert a String to an int primitiveint age = Integer.parseInt("25"); 
// Convert a String to a double primitivedouble price = Double.parseDouble("19.99"); 
// Convert a String to a boolean primitive (Accepts "true" case-insensitive, everything else is false)boolean isActive = Boolean.parseBoolean("true"); 

## Finding Data Limits
Wrapper classes store the absolute minimum and maximum values that a data type can hold on your computer architecture:
```java
System.out.println("Max Integer value: " + Integer.MAX_VALUE); // 2,147,483,647
System.out.println("Min Double value: " + Double.MIN_VALUE);   // 4.9E-324
```

## 3. A Critical Trap: The NullPointerException
Because wrapper classes are objects, their default value is null, whereas primitives have default values like 0 or false. If you attempt to unbox a wrapper object that is currently null into a primitive, Java will crash with a NullPointerException.
```java
Integer standardBonus = null;
// CRASH! Java tries to pull an int value out of a variable pointing to nothing
int finalBonus = standardBonus + 10; 
```
