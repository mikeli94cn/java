In Java, declaring and initializing variables is the two-step process of naming a data container and giving it a starting value. Because Java is strongly typed, you must specify exactly what kind of data a variable will hold before you can use it.

------------------------------
## 1. Declaration vs. Initialization

* Declaration: Specifying the data type and giving the variable a unique name. This tells the computer to set aside memory for it.
* Initialization: Assigning an initial value to that declared variable using the assignment operator (=).

You can perform these actions separately or combine them into a single line:

// Option 1: Declaring first, then initializing laterint score;         // Declaration
score = 100;       // Initialization
// Option 2: Declaring and initializing in one step (Most Common)double price = 19.99; 
String username = "Alex";

------------------------------
## 2. Primitive Type Casting
Casting is the process of converting a value from one primitive data type to another. In Java, this happens in two ways depending on the sizes of the data types involved.
To visualize the hierarchy of data sizes, remember this direction:
byte $\rightarrow$ short $\rightarrow$ char $\rightarrow$ int $\rightarrow$ long $\rightarrow$ float $\rightarrow$ double
## Widening Casting (Implicit / Automatic)
Widening occurs automatically when you pass a smaller data type to a larger data type. There is no risk of losing data, so Java handles it behind the scenes.

int standardInteger = 42;double wideDouble = standardInteger; // Automatic casting!

System.out.println(standardInteger); // Outputs: 42
System.out.println(wideDouble);      // Outputs: 42.0

## Narrowing Casting (Explicit / Manual)
Narrowing occurs when you convert a larger data type to a smaller data type. Because data could be truncated or lost, Java will throw a compiler error if you don't do it intentionally. You must perform this manually by placing the target data type in parentheses directly in front of the value.

double originalDecimal = 9.78;// Manual casting required: double to intint truncatedInteger = (int) originalDecimal; 

System.out.println(originalDecimal);   // Outputs: 9.78
System.out.println(truncatedInteger); // Outputs: 9 (Notice the decimal is completely cut off!)

------------------------------
## 3. Crucial Rules to Remember

* Variable Names (Identifiers): Must start with a letter, $, or _. By convention, Java variables use camelCase (e.g., totalPrice, userAge).
* The Default Literal Types: Whole numbers are treated as int by default, and decimals are treated as double by default.
* Appending Suffixes: Because of default types, you must add an f to initialize a float and an L to initialize a large long:

float distance = 5.25f; long globalPopulation = 8000000000L;


------------------------------
## Summary of Casting

| Casting Type | Direction | Conversion Style | Risk of Data Loss? |
|---|---|---|---|
| Widening | Smaller $\rightarrow$ Larger | Automatic by compiler | No risk |
| Narrowing | Larger $\rightarrow$ Smaller | Manual using (type) | Yes (decimals cut off / overflow) |
