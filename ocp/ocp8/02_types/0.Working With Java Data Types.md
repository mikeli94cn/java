In Java, data types specify the size and type of values that a variable can store. Because Java is a strongly typed language, every single variable must have a declared data type before it can be used in your code.
Java categorizes its data types into two completely distinct groups: Primitive Types and Reference Types. Understanding the differences between how these two groups store data is critical for writing efficient Java programs.


## 1. Primitive Data Types
Primitive types are the most basic, built-in data types predefined by Java. They store their data values directly in the computer's memory (the stack). There are exactly 8 primitive data types in Java, which can be grouped by the type of data they hold:
## Whole Numbers (Integers)

* byte: Extremely small. Stores whole numbers from -128 to 127. (Size: 1 byte).
* short: Stores whole numbers from -32,768 to 32,767. (Size: 2 bytes).
* int: The default choice for whole numbers. Stores values from roughly -2 billion to 2 billion. (Size: 4 bytes).
* long: Used for massive whole numbers. You must append an L to the end of the number (e.g., long population = 8000000000L;). (Size: 8 bytes).

## Floating-Point Numbers (Decimals)

* float: Sufficient for storing 6 to 7 decimal digits. You must append an f to the end of the number (e.g., float price = 10.99f;). (Size: 4 bytes).
* double: The default choice for decimals. Sufficient for storing up to 15 decimal digits. (Size: 8 bytes).

## Text & Logic

* char: Stores a single character or ASCII/Unicode value. Must be wrapped in single quotes (e.g., char grade = 'A';). (Size: 2 bytes).
* boolean: Stores a simple logical state: either true or false. (Size: 1 bit).


## 2. Reference (Non-Primitive) Data Types
Reference types are more complex structures created by the programmer (except for String, which is built-in). Instead of holding the actual value directly, a reference variable holds a memory address (a reference) that points to where the actual object is stored in memory (the heap).

* String: Used to hold sequences of characters wrapped in double quotes (e.g., String name = "Java";).
* Arrays: Containers that hold multiple values of the same type (e.g., int[] scores = {90, 85, 70};).
* Classes & Interfaces: Custom types that you define in your code.


## Key Differences: Primitive vs. Reference Types

| Feature | Primitive Types | Reference Types |
|---|---|---|
| What it stores | The actual value directly in memory. | A memory address pointing to an object. |
| Default Value | 0, 0.0, false, or \u0000 (never empty). | Can be null (meaning it points to nothing). |
| Methods | Cannot call methods (e.g., age.toString() fails). | Can call built-in methods (e.g., name.toLowerCase()). |
| Memory Location | Fast access, stored on the Stack. | Dynamically allocated, stored on the Heap. |


## Primitive Type Casting (Conversion)
Sometimes you need to convert a value from one data type to another. Java handles this in two ways:
## Widening Casting (Implicit / Automatic)
Converting a smaller type to a larger type size. Java handles this automatically because there is no risk of losing data.

int myInt = 9;double myDouble = myInt; // Automatic casting: int to double (9.0)

## Narrowing Casting (Explicit / Manual)
Converting a larger type to a smaller type size. Because data could be cut off or lost, you must manually place the target type in parentheses in front of the value.

double myDouble = 9.78;int myInt = (int) myDouble; // Manual casting: double to int. myInt becomes 9 (truncates decimal)
