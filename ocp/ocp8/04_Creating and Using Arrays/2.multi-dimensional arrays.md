While a one-dimensional array represents a single row of items, a multi-dimensional array is essentially an array of arrays. The most common type is a two-dimensional (2D) array, which is best visualized as a grid or a spreadsheet matrix containing rows and columns.
To use a multi-dimensional array, you follow the same progression: Declare, Instantiate, Initialize, and Use.

------------------------------
## 1. The 2D Array Lifecycle (Rows and Columns)
In Java, the first set of square brackets [] always represents the row, and the second set represents the column.
## Step 1: Declare the Array
You add two sets of square brackets to signal a two-dimensional structure.

int[][] seatGrid; // Declares a 2D array that will hold integers

## Step 2: Instantiate the Array
You must specify the dimensions (number of rows and columns) using the new keyword.

seatGrid = new int[3][4]; // Allocates memory for a matrix of 3 rows and 4 columns (12 total slots)

## Step 3: Initialize the Array (Assigning Values)
To target a specific slot, you must provide both its row index and column index (both starting at 0).

seatGrid[0][0] = 10; // First row, first column
seatGrid[0][1] = 20; // First row, second column
seatGrid[2][3] = 99; // Third (last) row, fourth (last) column

------------------------------
## 2. The Shortened Syntax (Inline Initialization)
If you already know your data layout, you can define a 2D array inline by nesting curly braces {}. Each inner set of curly braces represents a single row.

// A matrix with 3 rows and 3 columnsint[][] matrix = {
    {1, 2, 3},  // Row 0
    {4, 5, 6},  // Row 1
    {7, 8, 9}   // Row 2
};

------------------------------
## 3. Iterating Through Multi-Dimensional Arrays
To step through every element inside a multi-dimensional array, you must nest your loops. An outer loop tracks the rows, and an inner loop tracks the columns inside that row.
## Option A: Using Nested Traditional for Loops
The property matrix.length gives you the number of rows. To get the number of columns in a specific row, you check matrix[row].length.

for (int row = 0; row < matrix.length; row++) {
    for (int col = 0; col < matrix[row].length; col++) {
        System.out.print(matrix[row][col] + " ");
    }
    System.out.println(); // Prints a new line after completing a full row
}

## Option B: Using Nested Enhanced for-each Loops
If you don't care about the index coordinates and just want to read the data, this syntax is much cleaner:

for (int[] singleRow : matrix) {       // Pulls out an entire row array
    for (int element : singleRow) {    // Pulls out each individual integer in that row
        System.out.print(element + " ");
    }
    System.out.println();
}

------------------------------
## 4. Advanced Concept: "Jagged" Arrays
Because Java treats multi-dimensional arrays as an "array of arrays," the rows do not actually have to be the same length. An array with varying row lengths is called a jagged array.

int[][] jagged = new int[3][]; // Define 3 rows, but leave columns unallocated
jagged[0] = new int[2];        // Row 0 has 2 columns
jagged[1] = new int[5];        // Row 1 has 5 columns
jagged[2] = new int[1];        // Row 2 has 1 column
