In Java, filtering a collection means inspecting a data structure and extracting or retaining only the elements that match specific criteria []. Prior to Java 8, filtering required writing bulky for loops filled with manual if-else condition flags.

Today, Java handles filtering using Lambda expressions [] paired with either the Stream API (to extract data safely into a new list) [] or the removeIf method (to modify an existing collection directly).

------------------------------
## 1. The Core Engine: The Predicate Interface
When you write a lambda expression to filter data, you are fulfilling a functional contract called a Predicate []. A predicate lambda takes one input argument and returns a boolean value (true or false) [].

// Lambda matching any name longer than 5 characters
name -> name.length() > 5  

------------------------------
## 2. Method 1: Functional Filtering (The Stream Pipeline)
This is the most common and recommended approach []. It uses .filter() inside a stream pipeline []. This method leaves your original data collection completely untouched and compiles the filtered results into a brand-new list [].

import java.util.List;import java.util.stream.Collectors;
public class StreamFilterDemo {
    public static void main(String[] args) {
        List<String> frameworkList = List.of("Java", "Python", "JavaScript", "C++", "Julia");

        // --- FILTERING INTO A NEW LIST ---
        List<String> jFrameworks = frameworkList.stream() // 1. Open Stream Pipeline []
            .filter(lang -> lang.startsWith("J"))         // 2. Pass Lambda Filter rule []
            .collect(Collectors.toList());               // 3. Compile remaining data into a new List []

        System.out.println("Original List: " + frameworkList); // [Java, Python, JavaScript, C++, Julia] (Unchanged!)
        System.out.println("Filtered List: " + jFrameworks);   // [Java, JavaScript, Julia]
    }
}

------------------------------
## 3. Method 2: In-Place Filtering (Collection.removeIf)
If your goal is to mutate your original ArrayList and permanently destroy any items that don't belong, you use the .removeIf() method.

* Crucial Difference: While a Stream filter retains elements that evaluate to true [], .removeIf() deletes elements that evaluate to true.

import java.util.ArrayList;import java.util.List;
public class RemoveIfDemo {
    public static void main(String[] args) {
        // Must use an editable ArrayList, as List.of() is immutable
        List<Integer> prices = new ArrayList<>(List.of(15, 120, 45, 300, 85));

        // Delete any price item that is cheaper than $100
        prices.removeIf(price -> price < 100);

        System.out.println("Remaining Luxury Prices: " + prices); 
        // Outputs: Remaining Luxury Prices: [120, 300]
    }
}

------------------------------
## Summary Architectural Choice

| Feature Criteria | Stream Filter (.stream().filter()) | Collection Modification (.removeIf()) |
|---|---|---|
| Original Data Status | Left completely untouched (Immutable design) []. | Permanently mutated (Destructive design). |
| Lambda Logic Rule | Retains elements that match true []. | Deletes elements that match true. |
| Result Type | Outputs a brand-new, customized stream or list []. | Modifies the existing data type container directly. |
| Best Used For... | Data analysis, pipelines, or read-only transformation reporting []. | Standard cleanup maintenance on editable inventory collections. |
