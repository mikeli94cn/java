In Java, operators are special symbols used to perform calculations, compare values, and manipulate data. Because mathematical expressions can get complex, Java uses a strict ruleset called operator precedence to determine the exact order in which operations are evaluated.

When you want to alter or guarantee this order, you use parentheses ( ), which have the highest priority in the language.


## 1. Common Types of Java Operators
Java groups its operators based on the type of functionality they perform:

* Arithmetic Operators: Used for calculations: + (addition), - (subtraction), * (multiplication), / (division), and % (modulo, which returns the remainder of a division).
* Relational/Comparison Operators: Used to compare values, returning true or false: == (equal to), != (not equal to), > (greater than), and < (less than).
* Logical Operators: Used to combine multiple conditions: && (Logical AND), || (Logical OR), and ! (Logical NOT).


## 2. Understanding Operator Precedence
When multiple operators appear in a single line of code, Java doesn't simply read them from left to right. It evaluates them based on a hierarchy of importance (similar to standard PEMDAS algebra rules).
## The Default Precedence Order (Highest to Lowest):
```text
   1. Multiplicative: *, /, %
   2. Additive: +, -
   3. Relational: <, >, <=, >=
   4. Equality: ==, !=
   5. Logical AND: &&
   6. Logical OR: ||
```
## Example of Default Behavior:
```java
int result = 10 + 5 * 2; 
```

* What happens: Java looks at the line, sees that multiplication * has higher precedence than addition +, evaluates 5 * 2 first to get 10, and then adds 10.
* The final value of result: 20


## 3. Overriding Precedence with Parentheses ( )
If you want the addition to happen before the multiplication, you must explicitly group the addition inside parentheses. Parentheses override all other operators, forcing the JVM to evaluate their contents first.
## Example of Overriding Behavior:
```java
int overriddenResult = (10 + 5) * 2;
```

* What happens: Java is forced to evaluate 10 + 5 first because it is inside parentheses, resulting in 15. It then multiplies 15 * 2.
* The final value of overriddenResult: 30


## 4. Overriding Logical Precedence
Parentheses aren't just for math; they are equally critical for combining logical operations. By default, && (AND) takes precedence over || (OR).
Consider a system checking if a user can access a premium feature:
```java
boolean isPremium = true;boolean isUnlocked = false;boolean isAdmin = false;
// Default evaluation: (isUnlocked && isAdmin) happens first
boolean access1 = isPremium || isUnlocked && isAdmin; // Evaluates to: true || (false && false) -> true || false -> TRUE
// Overridden evaluation: forcing the OR statement first
boolean access2 = (isPremium || isUnlocked) && isAdmin;// Evaluates to: (true || false) && false -> true && false -> FALSE
```

## Summary Cheat Sheet

| Code Example | How Java Evaluates It | Final Result | Key Takeaway |
|---|---|---|---|
| 2 + 3 * 4 | 2 + (3 * 4) | 14 | Multiplication happens first by default. |
| (2 + 3) * 4 | 5 * 4 | 20 | Parentheses force addition first. |
| 12 / 2 * 3 | (12 / 2) * 3 | 18 | Equal precedence (/ and *) reads left-to-right. |
