In programming, conditional constructs allow your application to make decisions. They evaluate a condition (a expression that results in true or false) and change the direction of the program based on that result.

Java offers three primary ways to handle decisions: the straightforward if statement, the dual-path if/else block, and the compact ternary operator.


## 1. The Simple if Statement
An if statement executes a block of code only if its condition evaluates to true. If the condition is false, Java simply skips over the entire block.
```java
int speed = 75;
if (speed > 70) {
    System.out.println("Slow down! You are speeding.");
}
```

## 2. The if / else Structure
An if/else structure provides a fallback. It creates two separate paths: one that runs if the condition is true, and another alternative path that runs if it evaluates to false.
```java
int accountBalance = 150;int itemCost = 200;
if (accountBalance >= itemCost) {
    System.out.println("Purchase approved!");
} else {
    System.out.println("Transaction declined: Insufficient funds.");
}
```
### Chaining with else if
If you have more than two possible outcomes, you can chain multiple conditions together using else if:
```java
int score = 85;
if (score >= 90) {
    System.out.println("Grade: A");
} else if (score >= 80) {
    System.out.println("Grade: B"); // This block will execute
} else {
    System.out.println("Grade: C or below");
}
```

## 3. The Ternary Operator (? :)
The ternary operator is a shorthand, single-line alternative to a standard if/else statement. It is typically used when you want to quickly assign a value to a variable based on a single condition.
It is called "ternary" because it takes three operands:
```java
variable = (condition) ? value_if_true : value_if_false;
```
### Comparison: if/else vs. Ternary
Let's look at how the exact same decision-making logic looks in both formats:
Using standard if/else:
```java
int time = 20; // 8 PM
String greeting;
if (time < 18) {
    greeting = "Good day";
} else {
    greeting = "Good evening";
}
```
Using the Ternary Operator:
```java
int time = 20;
// Reads as: Is time less than 18? If yes, choose "Good day". If no, choose "Good evening".
String greeting = (time < 18) ? "Good day" : "Good evening";
```

## Summary Rules for Choosing Your Tool

| Construct | Best Use Case | Visual Style |
|---|---|---|
| if | When you only care about an action happening under one specific condition. | Single block. |
| if / else | When you have two or more distinct paths or complex nested logic. | Multiple branched blocks. |
| Ternary (? :) | When you want to cleanly assign a value in a single, highly readable line. | Inline expression. |
