When your program needs to choose between multiple distinct options based on the value of a single variable, a switch statement is often a cleaner, more readable alternative to a long chain of if-else if blocks.
Instead of evaluating true/false conditions, a switch statement takes an expression and jumps directly to the matching case label.

------------------------------
## 1. The Traditional switch Statement (With break)
The traditional switch layout compares an expression against multiple values. You must manually add a break keyword at the end of each case block. Without a break, the program will continue executing the code in the next cases automatically—a behavior known as fall-through.

int dayOfWeek = 3; 
switch (dayOfWeek) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    case 3:
        System.out.println("Wednesday"); // Program jumps here and prints
        break;                           // Exits the switch block immediately
    case 4:
        System.out.println("Thursday");
        break;
    default:
        System.out.println("Invalid day / Weekend");
        break;
}

## What does default do?
The default case acts like the final else in an if-else chain. If none of the defined case values match the expression, the code under default executes.
------------------------------
## 2. The Modern switch Expression (Arrow Syntax)
Introduced in newer versions of Java (Java 14+), the switch expression uses an arrow (->) syntax. This modern layout completely eliminates the risk of accidental fall-through bugs and allows you to return a value directly from the switch block.

int dayOfWeek = 3;
// Clean arrow syntax: No break statements required!
String dayName = switch (dayOfWeek) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    case 4 -> "Thursday";
    default -> "Invalid day";
};

System.out.println(dayName);

------------------------------
## Supported Data Types
You cannot use a switch statement on just any variable. Java restricts the types of data a switch statement can evaluate to:

* Primitives: char, byte, short, and int.
* Objects: String (highly common).
* Special Types: Enumerations (enum) and Wrapper classes (Character, Byte, Short, Integer).
* Note: Floating-point numbers (float, double) and boolean values are not allowed.

------------------------------
## Direct Comparison: if-else vs. switch

| Criteria | if-else Chain | switch Statement |
|---|---|---|
| Condition Style | Can evaluate complex ranges, inequalities, and multiple variables (e.g., age > 21 && score == 100). | Evaluates exact matches against a single variable or expression (e.g., day == 3). |
| Readability | Can become bulky and hard to read with 5+ choices. | Highly structured and clean for mapping many distinct values. |
| Performance | Evaluates conditions sequentially from top to bottom. | Can be optimized by the compiler via a lookup table to jump straight to the correct code. |
