In the Java Stream API, once you have filtered or transformed a collection of data, you often need to perform structural calculations to extract final answers. The API divides these into Calculation Methods (which reduce a stream down to a single numeric summary) and specialized Data Methods (such as sorting, grouping, or flattening nested layers) [].

Rather than writing multi-line loop trackers, these methods allow you to execute advanced statistical mathematics or array modifications in a single declarative step.

------------------------------
## 1. High-Speed Calculation Methods
When processing numeric streams, calculating basic aggregates is built directly into the framework. However, there is an important architectural requirement: to access mathematical methods like .sum() or .average(), you must first convert your generic Stream<Object> into a primitive stack stream using methods like .mapToInt() or .mapToDouble() [].

* .count(): Returns a primitive long tracking how many elements made it to the end of the pipeline [].
* .sum(): Adds up all numbers in a primitive stream, returning int, long, or double.
* .average(): Calculates the arithmetic mean, returning an OptionalDouble (to protect your app from crashing if the stream was empty).
* .max() / .min(): Finds the highest or lowest numeric boundary, returning a specialized primitive Optional (e.g., OptionalInt).

## The Ultimate Shortcut: .summaryStatistics()
If you need to calculate all of these metrics at the exact same time, you don't need to run five separate pipelines. You can call .summaryStatistics() to instantly compile a comprehensive numeric data report.

import java.util.IntSummaryStatistics;import java.util.List;

List<Integer> finalScores = List.of(88, 92, 45, 100, 71);

IntSummaryStatistics stats = finalScores.stream()
    .mapToInt(Integer::intValue) // Convert to an IntStream
    .summaryStatistics();        // Compile everything all at once

System.out.println("Average Score: " + stats.getAverage()); // 79.2
System.out.println("Highest Score: " + stats.getMax());     // 100
System.out.println("Total Samples: " + stats.getCount());   // 5

## 2. Core Stream Data Methods
When you need to adjust the structure, composition, or flow layout of data passing through the pipeline, you use specialized intermediate data methods:

* .distinct(): Removes any duplicate items from the stream based on their .equals() footprint [].
* .sorted(): Organizes the elements into a specific sorting pattern []. You can let items sort by their natural order or pass a custom Comparator mapping rule [].
* .limit(long maxSize): A short-circuiting operation that chops the stream off after a set number of elements pass through, ignoring any remaining data.
* .skip(long n): Ignores the first n elements traveling down the pipe, allowing only subsequent elements to continue.

## 3. Code Blueprint: Advanced Data Calculation
Imagine an e-commerce platform processing a list of customer transactions. We want a pipeline that eliminates duplicate testing entries (distinct), extracts just the numeric values into a primitive stack stream (mapToDouble), and runs multiple financial checks simultaneously.

import java.util.DoubleSummaryStatistics;import java.util.List;
class Transaction {
    private String orderId;
    private double amount;

    public Transaction(String orderId, double amount) {
        this.orderId = orderId;
        this.amount = amount;
    }
    public double getAmount() { return amount; }
    
    // Overriding equals and hashCode so .distinct() can identify duplicates
    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        return this.orderId.equals(((Transaction) obj).orderId);
    }
    @Override
    public int hashCode() { return orderId.hashCode(); }
}
public class StreamCalculationDemo {
    public static void main(String[] args) {
        List<Transaction> ledger = List.of(
            new Transaction("TX-101", 150.00),
            new Transaction("TX-102", 45.00),
            new Transaction("TX-101", 150.00), // 🚨 DUPLICATE SYSTEM LOG Entry!
            new Transaction("TX-103", 1200.00),
            new Transaction("TX-104", 310.00)
        );

        System.out.println("--- Compiling Financial Ledger Metrics ---");

        // Execute unified data calculation pipeline
        DoubleSummaryStatistics runningLedgerStats = ledger.stream()
            .distinct()                     // 1. DATA METHOD: Filter out duplicate logs
            .mapToDouble(Transaction::getAmount) // 2. TRANSFORMATION: Extract primitive doubles
            .summaryStatistics();           // 3. CALCULATION METHOD: Compute aggregates instantly

        System.out.printf("Total Corporate Revenue: $%.2f%n", runningLedgerStats.getSum());
        System.out.printf("Average Invoice Value:   $%.2f%n", runningLedgerStats.getAverage());
        System.out.printf("Largest Single Order:    $%.2f%n", runningLedgerStats.getMax());
    }
}

## Summary Architectural Capability Matrix

| Pipeline Method | Category | Return Value Type | Performance Impact Behavior |
|---|---|---|---|
| .distinct() | Data Method | Stream<T> (Intermediate) [] | Stateful. Must remember previous objects to spot duplicates []. |
| .sorted() | Data Method | Stream<T> (Intermediate) [] | Stateful & Blocking. Must collect 100% of data before sorting can begin []. |
| .limit(n) | Data Method | Stream<T> (Intermediate) | Short-Circuiting. Shuts down the stream early once count n is hit. |
| .sum() | Calculation | Primitive Numeric (int/double) | Terminal. Closes the pipeline stream instantly. |
| .average() | Calculation | OptionalDouble | Terminal. Closes the pipeline stream instantly. |
| .summaryStatistics() | Calculation | Comprehensive Summary Object | Terminal. Computes count, sum, min, average, and max simultaneously. |
