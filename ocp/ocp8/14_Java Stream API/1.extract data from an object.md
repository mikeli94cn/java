In the Java Stream API, processing complex collection data frequently requires transforming object properties or inspecting items as they flow down a functional data pipeline. To handle these transitions cleanly, Java provides the map() and peek() methods.

While they look similar because they both step through elements sequentially, they serve completely opposite architectural goals: map() changes data, while peek() simply observes data without altering it [].

------------------------------
## 1. map() vs. peek() (The Core Distinction)

* map(Function) (Data Transformation): This is a core intermediate operation that transforms each element in the stream into something else []. It takes an input, processes it, and returns a new data value or a completely different data type (e.g., extracting an integer field out of a complex object) [].
* peek(Consumer) (Pipeline Inspection): This operation performs an action on elements without changing them []. It is primarily used for debugging or logging, allowing you to see what an object looks like at a specific point in the pipeline before an optimization or transformation takes place [].

------------------------------
## 2. Bypassing Memory Overhead: Primitive Map Specializations
If you use a standard .map() method to extract numeric data (like an integer ID or a decimal price), Java is forced to wrap those values inside generic Object structures (like Integer or Double). This performance-draining process is known as autoboxing [].
To maximize execution speeds and keep calculations isolated on the fast memory stack, the Stream API provides built-in primitive versions of the map method:

* mapToInt(ToIntFunction): Converts the stream into a high-speed IntStream.
* mapToLong(ToLongFunction): Converts the stream into a LongStream.
* mapToDouble(ToDoubleFunction): Converts the stream into a DoubleStream.

Beyond cutting down memory usage, these primitive streams unlock powerful built-in mathematical aggregate functions—such as .sum(), .max(), and .average()—that are completely missing from standard object streams.
------------------------------
## 3. Code Blueprint: Extracting and Inspecting Object Data
Imagine a corporate inventory platform tracking a list of Appliance entries. We want a pipeline that logs each item for tracking visibility (peek), extracts just their numeric costs into a stack-isolated stream (mapToDouble), and calculates the total sum of the inventory automatically.

import java.util.List;
class Appliance {
    private String modelName;
    private double cost;

    public Appliance(String modelName, double cost) {
        this.modelName = modelName;
        this.cost = cost;
    }
    public String getModelName() { return modelName; }
    public double getCost() { return cost; }
}
public class StreamExtractionDemo {
    public static void main(String[] args) {
        List<Appliance> stock = List.of(
            new Appliance("Refrigerator", 1200.00),
            new Appliance("Microwave", 150.00),
            new Appliance("Dishwasher", 650.00)
        );

        System.out.println("--- Starting Stream Data Pipeline Extraction ---");

        // Execute pipeline
        double totalInventoryValue = stock.stream()
            // 1. PEEK: Log the raw objects for debugging visibility (Does NOT change data)
            .peek(item -> System.out.println("[DEBUG-LOG] Processing Model: " + item.getModelName()))
            
            // 2. PRIMITIVE MAP: Extract raw doubles directly, converting Stream<Appliance> into a DoubleStream
            .mapToDouble(Appliance::getCost) 
            
            // 3. TERMINAL OPERATION: Sum up the primitives cleanly
            .sum(); 

        System.out.println("\nFinal Calculation Completed.");
        System.out.printf("Total Stack Valuation: $%.2f%n", totalInventoryValue);
    }
}

## Summary Architectural Matrix

| Pipeline Method | Stream Output Type | Action Category | Primary Use Case Goal |
|---|---|---|---|
| .peek(Consumer) | Retains original stream type. | Observation (Read-Only) [] | Diagnostic logging or printing midway through a pipeline []. |
| .map(Function) | Stream<R> (Altered Object type) [] | Transformation [] | Converting one object identity to an alternative object layout []. |
| .mapToInt() | IntStream (Primitive stack) | Primitive Extraction | Isolating raw integer values to optimize speed or run math filters. |
| .mapToDouble() | DoubleStream (Primitive stack) | Primitive Extraction | Pulling monetary rates or decimal metrics out of a system entity. |
