In Java, a standard array has a fixed capacity that cannot be altered after creation. To solve this limitation, Java provides the ArrayList class (located in the java.util package).
An ArrayList represents a dynamically resizable array. It automatically expands its capacity as you add new items and shrinks as elements are removed.
------------------------------
## 1. The Syntax of Declaration and Instantiation
When you declare an ArrayList, you use Generics—signaled by angle brackets < >—to specify the exact data type the list is allowed to hold.
## The Rule of Primitives:
An ArrayList can only store objects, not primitive types. If you want a list of integers or decimals, you must declare it using their corresponding Wrapper Classes (Integer, Double, Boolean, etc.) instead of int, double, or boolean.

import java.util.ArrayList; // Mandatory import
public class Main {
    public static void main(String[] args) {
        // Standard syntax: Specifying type on both sides
        ArrayList<String> names = new ArrayList<String>();

        // Modern shorthand (The Diamond Operator '<>'): Omit type on the right side
        ArrayList<Integer> scores = new ArrayList<>(); 
    }
}

------------------------------
## 2. Core Methods for Manipulating an ArrayList
ArrayList features an intuitive suite of built-in methods used to modify and read data.
## .add(element) (Inserting Data)
Appends an element onto the very end of the list. You can also pass an index number first to force-inject an item into a specific slot.

ArrayList<String> roster = new ArrayList<>();

roster.add("Alex"); // Adds to index 0
roster.add("Blake"); // Adds to index 1
roster.add(1, "Charlie"); // Injects at index 1, shifting Blake down to index 2
// List layout: ["Alex", "Charlie", "Blake"]

## .get(index) (Reading Data)
Retrieves the element sitting at a specific zero-based index coordinate. (Note: Using roster[index] syntax like a standard array will throw a compiler error).

String secondPlayer = roster.get(1); 
System.out.println(secondPlayer); // Outputs: Charlie

## .set(index, newElement) (Updating Data)
Overwrites the item currently sitting at that index location with an alternative value.

roster.set(2, "David"); // Replaces "Blake" with "David"

## .remove(index) or .remove(Object) (Deleting Data)
Removes an item by its coordinate location or by searching for the exact matching object value. When an item is removed, the remaining items shift left to plug the hole.

roster.remove(0); // Deletes "Alex". "Charlie" now slides up to index 0.
roster.remove("David"); // Searches the list and deletes the string "David".

## .size() (Checking Capacity)
Returns the total number of elements currently stored inside the list (equivalent to .length on a regular array).

System.out.println("Total active items: " + roster.size());

------------------------------
## 3. Iterating Through an ArrayList
You can easily step through an ArrayList using either a traditional for loop or a clean enhanced for-each loop:

ArrayList<String> tools = new ArrayList<>();
tools.add("Hammer");
tools.add("Wrench");
// Option A: Enhanced for-each loop (Recommended for simple reading)for (String tool : tools) {
    System.out.println("Tool: " + tool);
}
// Option B: Traditional for loop (Best if you need to track index numbers)for (int i = 0; i < tools.size(); i++) {
    System.out.println("Tool at index " + i + ": " + tools.get(i));
}

------------------------------
## Summary Direct Comparison: Array vs. ArrayList

| Feature Metric | Standard Array ([]) | ArrayList Class |
|---|---|---|
| Capacity Style | Fixed size. Cannot expand or contract. | Dynamic size. Resizes dynamically. |
| Supported Data Types | Accepts both primitive types and objects. | Strict requirement: Objects only (requires wrappers). |
| Syntax for Size | array.length (Property) | list.size() (Method) |
| Accessing Elements | Direct bracket access (array[0]). | Method access (list.get(0)). |
