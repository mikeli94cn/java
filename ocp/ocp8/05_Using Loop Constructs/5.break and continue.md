In Java, break and continue are control statements used to abruptly alter the normal flow of loops (for, while, and do/while). They give you the power to stop a loop early or skip specific iterations based on custom conditions.

------------------------------
## 1. The break Statement (The Emergency Exit)
The break statement completely terminates the loop immediately. As soon as Java encounters a break, it jumps entirely out of the loop and starts executing the next line of code below the loop's closing brace.
## Use Case: Searching for an item
If you are searching an array of 1,000 items for a specific ID and you find it on the 3rd iteration, running the remaining 997 loops is a waste of computer processing power. You use break to exit early.

String[] inventory = {"Apple", "Banana", "TargetItem", "Orange", "Mango"};
for (String item : inventory) {
    if (item.equals("TargetItem")) {
        System.out.println("Found it! Stopping search.");
        break; // Exits the entire loop right here
    }
    System.out.println("Checking: " + item);
}
System.out.println("Loop finished.");

## Output:

Checking: Apple
Checking: Banana
Found it! Stopping search.
Loop finished.

------------------------------
## 2. The continue Statement (The Skip Button)
The continue statement does not stop the loop entirely. Instead, it stops the current iteration immediately and jumps straight to the loop's next iteration check (advancing the counter in a for loop, or re-evaluating the condition in a while loop).
## Use Case: Filtering out data
If you want to process a list of numbers but want to completely ignore negative values or zero, you use continue to skip over them.

for (int i = 1; i <= 4; i++) {
    if (i == 3) {
        continue; // Skips the rest of this code block for i = 3
    }
    System.out.println("Processing number: " + i);
}

## Output:

Processing number: 1
Processing number: 2
// Notice 3 is missing completely!
Processing number: 4

------------------------------
## Direct Contrast: Side-by-Side Comparison

| Statement | Effect on the Loop | Visual Action |
|---|---|---|
| break | Aborts the loop completely. Discards all remaining iterations. | Jumps to the outside bottom of the loop block. |
| continue | Skips the current turn. Moves straight to the next iteration. | Jumps back to the top header of the loop. |

------------------------------
## A Critical Trap with while Loops and continue
When using continue inside a traditional while loop, you must be extremely careful. If your update statement (like count++) is placed after the continue statement, your counter will never increment, trapping your program in an infinite loop.

// ❌ WARNING: INFINITE LOOP BUGint count = 1;while (count <= 4) {
    if (count == 3) {
        continue; // 🚨 BUG: Jumps to the top, count stays 3 forever!
    }
    System.out.println(count);
    count++; // This line is skipped when count is 3
}


* How to fix: Ensure you increment the tracking variable before calling continue in a while loop, or use a for loop which handles increments automatically in the header.
