In programming, a for loop is a control flow statement used to repeat a block of code a specific number of times. Java provides two distinct styles: the traditional for loop (ideal when you need an index or counter) and the enhanced for loop (ideal for cleanly stepping through a collection without managing counters).

------------------------------
## 1. The Traditional for Loop
A traditional for loop bundles three crucial expressions into a single line: Initialization, Condition, and Update. It is best used when you know exactly how many times you want the code to repeat.
## The Syntax:

for (initialization; condition; update) {
    // Code to repeat
}

## Working Example:

// Counts from 1 up to 3for (int i = 1; i <= 3; i++) {
    System.out.println("Count is: " + i);
}


* int i = 1 (Initialization): Creates a counter variable i and sets it to 1. This runs exactly once when the loop starts.
* i <= 3 (Condition): Checked before every iteration. If true, the code inside the block runs. If false, the loop ends.
* i++ (Update): Increments the counter by 1 after the code inside the block completes, then loops back to re-check the condition.

------------------------------
## 2. The Enhanced for Loop (For-Each)
Introduced to simplify array and collection navigation, the enhanced for loop (often called the for-each loop) completely eliminates the need for an index counter (i). Instead of managing a number, Java automatically gives you access to the actual next item in the collection sequentially.
## The Syntax:

for (DataType item : collection) {
    // Code to use the item directly
}

## Working Example:

String[] operations teams = {"Development", "Security", "Operations"};
// Reads as: "For each String named 'team' inside the 'teams' array..."for (String team : teams) {
    System.out.println("Department: " + team);
}

------------------------------
## Direct Comparison: Traditional vs. Enhanced
While both loops can iterate through arrays, their use cases differ significantly:

| Feature | Traditional for Loop | Enhanced for Loop (For-Each) |
|---|---|---|
| Control Element | Relies on an index / counter variable (e.g., i). | Relies on the actual data item directly. |
| Modification Ability | Can modify array elements (e.g., arr[i] = 10;). | Read-only. Modifying the loop variable does not change the underlying array. |
| Iteration Direction | Flexible (can skip elements, count backward, etc.). | Strict forward direction (starts at index 0 and reads every single item). |
| Syntax Bulk | Requires initialization, boundaries, and increments. | Ultra-clean, single-line extraction. |

## When to use which:

* Use the traditional loop if you need to know the index number (e.g., "Print only odd index slots") or if you need to overwrite values inside the array.
* Use the enhanced loop if you simply want to read or display every single item in a collection from start to finish.
