In programming, a do/while loop is a control flow statement that repeats a block of code based on a boolean condition. It is uniquely distinguished from standard while and for loops by one critical rule: it executes its code block first before checking the condition.
This structural difference guarantees that a do/while loop will always run at least once, regardless of whether the condition is true or false right from the start.

------------------------------
## 1. The Structure and Syntax of a do/while Loop
While a standard while loop checks the doorway before letting you in, a do/while loop lets you in once and then checks if you can stay.

do {
    // Code to execute (Always runs at least once!)
    // Update statement (to alter the condition variable)
} while (condition); // <-- CRITICAL: Note the mandatory semicolon here!

Here is a side-by-side comparison illustrating how a while loop and a do/while loop handle a condition that is already false:

// Scenario: The variable is already outside the allowed limitint checkNumber = 100;
// Option A: Standard while loopwhile (checkNumber < 10) {
    System.out.println("This will NEVER print.");
    checkNumber++;
}
// Option B: do/while loopdo {
    System.out.println("This WILL print exactly once!");
    checkNumber++;
} while (checkNumber < 10);

------------------------------
## 2. When to Use a do/while Loop
The primary use case for a do/while loop is any scenario where you must prompt, display, or calculate something first before you can evaluate whether you need to repeat the process.
## Real-World Example: User Input Validation Menu
A classic scenario is a game menu or text prompt. You must show the menu to the user at least once. After they interact with it, you check if they want to repeat the action or exit.

import java.util.Scanner;
public class QuizApp {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int answer;

        // The program guarantees the user gets asked the question at least once
        do {
            System.out.println("What is 5 + 5?");
            System.out.print("Your answer: ");
            answer = scanner.nextInt();
            
            if (answer != 10) {
                System.out.println("Incorrect! Try again.");
            }
        } while (answer != 10); // Loop repeats AS LONG AS the answer is wrong

        System.out.println("Correct! Well done.");
        scanner.close();
    }
}

## Summary Loop Comparison Table

| Loop Type | Minimum Iterations | When is the Condition Checked? | Best Use Case |
|---|---|---|---|
| for | 0 | Before the block runs (Top). | When you know the exact count of loops in advance. |
| while | 0 | Before the block runs (Top). | When looping depends on an external state or flag. |
| do/while | 1 | After the block runs (Bottom). | When you must run the action first (like menus or prompts). |
